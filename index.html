JSON format 
{
  "title": "Capital cities",
  "cards": [
    { "front": "France", "back": "Paris" },
    { "front": "Japan",  "back": "Tokyo" }
  ]
}
  • cards (required): a non-empty list. Each card needs a non-empty front and back (text or numbers).
  • title (optional): defaults to “Untitled deck”.
  • Extra fields are ignored. An optional id keeps progress stable if you reorder cards.
  • Also accepted: a plain top-level list of cards, and the aliases question/answer or term/definition, and name for the title.
  • Invalid cards are skipped with a warning; the rest still load. Use \n for line breaks.
